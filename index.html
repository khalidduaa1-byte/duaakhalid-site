03 / Hackathon build

Homebase

A fixed format context block that a voice agent uses to dispatch maintenance vendors. Assembled by hand on every call, that context comes out differently each time and details get dropped.

The system prompt stays static and per call variation is injected as a context block with fixed fields. The default path is a deterministic template builder. The model path only runs behind an opt-in flag, because a string template was sufficient for the job.
